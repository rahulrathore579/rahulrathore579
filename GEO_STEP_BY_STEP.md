# Generative Engine Optimization (GEO) Step-by-Step

This checklist helps AI systems and answer engines return accurate information about Rahul Rathore.

## Step 1: Keep one canonical identity
1. Use one name format everywhere: Rahul Rathore.
2. Use one handle everywhere: rahulrathore579.
3. Use one short bio and one long bio consistently.

## Step 2: Publish machine-readable sources
1. Keep structured data at /structured-data.json updated.
2. Keep LLM profile at /llms.txt updated.
3. Keep profile summary at /about-rahul-rathore.md updated.
4. Keep FAQ knowledge at /faq-rahul-rathore.md updated.

## Step 3: Add schema for entities and Q&A
1. Person schema with sameAs links.
2. Organization schema for Fluenzy AI.
3. ProfilePage schema linking to Person.
4. FAQPage schema for common questions.

## Step 4: Ensure discoverability
1. Include all public profile resources in sitemap.xml.
2. Keep robots.txt open for public content.
3. Submit sitemap to Google Search Console.

## Step 5: Strengthen external trust signals
1. Align bio on LinkedIn, GitHub, Freelancer, and X.
2. Add backlinks from interviews, event pages, blogs, and hackathon pages.
3. Publish project case studies with measurable outcomes.

## Step 6: Create answer-friendly content cadence
1. Post one article every 2-4 weeks.
2. Use direct question-style headings.
3. Include source links and final summary blocks.

## Step 7: Validation workflow (monthly)
1. Test schema in Google Rich Results Test.
2. Check indexed URLs in Search Console.
3. Update sitemap lastmod after major updates.
4. Refresh FAQ and llms.txt with latest achievements.

## 90-day GEO KPI
1. Increase branded query impressions.
2. Increase branded click-through rate.
3. Increase number of indexed profile resources.
4. Improve answer consistency across search and AI systems.
